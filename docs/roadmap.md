# Implementation roadmap

The group agrees individual responsibilities separately from this technical roadmap.

1. **v0.1: shared foundation** - repository, event contract, sample, Kafka producer,
   Spark streaming to raw HDFS Bronze, local tests and integration verification.
2. **Silver lakehouse (implemented)** - Spark 3.5/Hudi Copy-on-Write table,
   event-ID upserts, invalid-event quarantine, and replay/schema/read checks.
3. **Gold analytics** - Spark SQL rankings and trends; repository language enrichment;
   Gold Hudi metrics; MLlib KMeans features, training, and evaluation.
4. **Automation and visualization** - integrated real-data and sample/demo DAGs,
   hourly processing, quality checks, retraining, Hudi export, transactional SQL
   publication and Superset activity/growth dashboards.
5. **Final verification and deliverables** - complete-hour capacity/recovery tests,
   final French cahier des charges, results-based final report, slides and rehearsal.

The general guide requires the cahier des charges near the start of the project.
Its PDF is a separate deliverable and is not generated by this code starter.
